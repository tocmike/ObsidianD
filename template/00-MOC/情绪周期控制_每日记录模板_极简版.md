## 🛑 风控动作（勾选）
### 📉 亏损情绪 L0–L9（Loss）
- [ ] **L0** ✅按计划 / 只做A+ / 下单前10秒checklist
- [ ] **L1** 🧠风险不变 / 复盘后再下单 / 不改系统
- [ ] **L2** ⏳仓位70% / 次数-30% / 间隔≥10分钟
- [ ] **L3** 🧷仓位50% / 只做1-2个setup / 禁止加仓补仓
- [ ] **L4** 👀轻仓验证或观察 / 严格止损 / 减少盯盘
- [ ] **L5** 🚫停实盘 / 只复盘统计截图 / 写“可控3件事”
- [ ] **L6** 🧊至少24h不交易 / 只做事实复盘 / 不做大改
- [ ] **L7** 🏃离开软件 / 运动20分钟 / 说出“我想赌”
- [ ] **L8** 🛌冻结账户或删App / 找可信的人 / 生活恢复
- [ ] **L9** 🧯长期停盘 / 资金&生活安全检查 / 必要时专业支持

### 📈 盈利情绪 G0–G5（Gain）
- [ ] **G0** ✅按计划 / 风险上限不变 / 继续记录
- [ ] **G1** ✍️每笔写“无效条件”一句
- [ ] **G2** 🍀仓位≤正常 / 只做核心 / 写“50%来自风控+运气”
- [ ] **G3** 🚫仓位70% / 禁止加杠杆 / 次数-30% / 不放宽止损
- [ ] **G4** 🧊强制停盘1天 / 锁利或提现 / 只统计复盘
