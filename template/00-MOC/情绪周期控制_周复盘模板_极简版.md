## 📎 本周日记索引（可选）
> 如果你用 Dataview，可以把下面 folder 改成你的“每日记录”目录。
```dataview
TABLE 日期, 今日净盈亏A, 今日净盈亏B, 交易次数, 最大回撤, 亏损情绪等级, 盈利情绪等级
FROM "交易/每日记录"
WHERE 日期 >= date(周起始) AND 日期 <= date(周结束)
SORT 日期 ASC
```
