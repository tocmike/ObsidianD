# 亏损情绪等级参考（0-9）

下面内容用于对照选择等级（你也可以在每条里继续补充“我的典型想法/触发情境/行为”）。

1. **0｜平静观察**
   - 状态描述（系统）:: 情绪平稳，能按计划执行，客观看待盈亏
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 正常按交易计划执行；记录交易；按规则开平仓
   - 禁止的行为（建议，可自行修改）:: 临时加杠杆；因为无聊而乱点单

2. **1｜轻微不适 / 轻度遗憾**
   - 状态描述（系统）:: 小亏损或错过机会，有点不爽但能接受
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 允许复盘当笔交易；可以少量调整但保留原风险框架
   - 禁止的行为（建议，可自行修改）:: 因一笔小亏立即改系统；立刻加仓想“赢回来”

3. **2｜烦躁 / 不耐烦**
   - 状态描述（系统）:: 连续几笔不顺，开始烦躁，频繁看盘
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 强制减低交易频率；只允许做最熟悉的 1–2 个 setup
   - 禁止的行为（建议，可自行修改）:: 频繁进出、盯盘到失去生活节奏；临时缩短/拉长止损

4. **3｜焦虑 / 持续紧绷**
   - 状态描述（系统）:: 开始心慌、睡前也在想交易，担心本月或本周目标完不成
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 降低仓位到平时的一半；写下焦虑点；只按既定策略操作
   - 禁止的行为（建议，可自行修改）:: 为了消除焦虑而“乱打一针”；任何临时改变系统核心参数

5. **4｜恐惧 / 逃避现实**
   - 状态描述（系统）:: 亏损对账户或生活产生压力，不敢看账户，开始拖止损
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 降仓或停止新开仓；必须严格执行既定止损；允许只做观察和复盘
   - 禁止的行为（建议，可自行修改）:: 不愿止损，任由浮亏扩大；从短线变“死扛长线”；赌徒式加码

6. **5｜明显痛苦 + 自我怀疑**
   - 状态描述（系统）:: 心在滴血，对自己能力开始怀疑，反复想这段亏损
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 当天起停止实盘；只允许做复盘、复查交易记录；写下学到的东西
   - 禁止的行为（建议，可自行修改）:: 任何实盘加仓或补仓；试图“一把翻身”；继续重仓

7. **6｜悔恨 + 强烈自责**
   - 状态描述（系统）:: 为已实现大亏或关键错误深度自责，反复重播当时画面
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 写冷静版复盘（事实+数据为主）；制定修正方案；至少休息 1–3 天再上场
   - 禁止的行为（建议，可自行修改）:: 在高情绪下立新系统；向家人/他人隐瞒真实亏损并继续暗中加码

8. **7｜愤怒（对自己 / 市场 / 他人）**
   - 状态描述（系统）:: 把怒气指向自己、市场或他人，想“赌一口气”
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 远离电脑与手机交易软件；进行运动、散步、和非交易相关活动
   - 禁止的行为（建议，可自行修改）:: 梭哈、逆势硬顶、报复性交易；任何带有“老子就不信了”情绪的下单

9. **8｜绝望 / 放弃感**
   - 状态描述（系统）:: 觉得怎么做都错，看不到希望，对交易和生活动力变弱
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 只允许做：总结过去+考虑是否阶段性退出实盘；与信任的人沟通现实情况
   - 禁止的行为（建议，可自行修改）:: 在绝望情绪下继续重仓；用借款、生活必需资金继续博弈

10. **9｜麻木 / 解离状态**
   - 状态描述（系统）:: 对巨额波动都无太大感觉，像在看别人的账户，“怎样都行”
   - 我的典型想法（填写）:: 
   - 我的触发情境（填写）:: 
   - 允许的行为（建议，可自行修改）:: 立即冻结所有新开仓行为；考虑长期停盘和心理/生活层面的调整
   - 禁止的行为（建议，可自行修改）:: 任何形式的继续交易；把大额资金当“游戏币”反复挥霍
