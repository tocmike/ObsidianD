# 如何建立自己的交易节奏
## 什么是交易节奏
### 四个节奏点

<span style="font-size: 20px; color: orange">> 市场节奏
> 板块节奏
> 个股节奏
> 自己的节奏</span>
> 最好是这 4 个节奏能产生共振，能起到最好的效果


## 自己节奏的 2 个前提:
1. 资金规模
2. 相对现实的目标
	 1. 500 w  20%
3. 不同的游戏，收益目标也不一样，德州，麻将，斗地主
4. 目标是 30，达到后只拿收益玩
5. <mark style="background-color: #1EFF00; color: black">节奏乱了，多少钱都会亏回去</mark>
6. 目标决定行为

### 资金规模与盈利目标

| 资金规模     | 盈利目标    |     |
| -------- | ------- | --- |
| 10 w 下   | 100%    |     |
| 10-50    | 70-100  |     |
| 50-100   | 50-70   |     |
| 100-300  | 30-50   |     |
| 300-500  | 20-30   |     |
| 500-1000 | 10%-20% |     |
| 5000     | 防风险     |     |

###  案例：小米
- 市场节奏：
	- 924 之前港股，港股先与 A 股走牛
	- A 股走牛的是，港股是稳住的
- 板块节奏：
	- 前期是大科技，
	- 消费很晚起的，甚至白酒都没动
- 个股节奏：
	- 腾讯属于指数贡献，小米是自己的节奏，还有新故事出来
	- 三千年和五粮液差别就很大
- 自己的节奏：、
	- 仓位配比
	- 错误就是，重仓安全板块，对看好的板块小仓位，瑞达期货
	- 3 个节奏没看懂


目前 12 月

	- A 股，港股都休息
- 板块节奏：
	- 商业航天，带起军工

## 四个节奏
### 市场节奏 : 
- 货币宽松周期 or 紧缩
	- QE 周期
	- 宽松周期，反弹随时来
		- 钱没地方去，但是需要找一个舒服的位置进去。
- 宽松周期有的是钱:
	- <span style="background-color: #fff88f; color: black">要么别下车，要么半只脚在车上</span>。
- 上涨 or下跌 or 横盘
	- 目前就是横盘，上有顶下有底，
	- <mark style="background-color: #fff88f; color: black">现在操作就是低吸高抛</mark>
		- 具体，所以就是拉起来就卖
		- 多看少动
