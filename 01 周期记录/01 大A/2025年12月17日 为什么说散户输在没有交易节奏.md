# 如何建立自己的交易节奏
## 什么是交易节奏
### 四个节奏点

<span style="font-size: 20px; color: orange">> 市场节奏
> 板块节奏
> 个股节奏
> 自己的节奏</span>
> 最好是这 4 个节奏能产生共振，能起到最好的效果


## 自己节奏的 2 个前提:
1. 资金规模
2. 相对现实的目标
	 1. 500 w  20%
3. 不同的游戏，收益目标也不一样，德州，麻将，斗地主
4. 目标是 30，达到后只拿收益玩
5. <mark style="background-color: #1EFF00; color: black">节奏乱了，多少钱都会亏回去</mark>
6. 目标决定行为

### 资金规模与盈利目标

| 资金规模     | 盈利目标    |     |
| -------- | ------- | --- |
| 10 w 下   | 100%    |     |
| 10-50    | 70-100  |     |
| 50-100   | 50-70   |     |
| 100-300  | 30-50   |     |
| 300-500  | 20-30   |     |
| 500-1000 | 10%-20% |     |
| 5000     | 防风险     |     |

## 四个节奏
### 市场节奏 : 
- 货币<mark style="background-color: #3ACADD; color: yellow">宽松周期</mark> or 紧缩
	1. QE 周期
	2. 宽松周期，反弹随时来
		- 钱没地方去，但是需要找一个舒服的位置进去。
- 宽松周期有的是钱:
	- <span style="background-color: #fff88f; color: black">要么别下车，要么半只脚在车上</span>。
- 上涨 or下跌 or <mark style="background-color: #3ACADD; color: yellow">横盘</mark>
	- 目前就是横盘，上有顶下有底，
	- <mark style="background-color: #fff88f; color: black">现在操作就是低吸高抛</mark>
		- 具体，所以就是拉起来就卖
		- 多看少动
- 如果在紧缩周期，那就只能玩个股，低仓位——以后再说
- 宽松周期，大的策略是指数贡献
