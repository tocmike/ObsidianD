### 实战中如何选择：PE 历史分位 vs PB 历史分位

- **90% 的普通行业看「PE 历史分位」**：
    
    - **适用标的**：消费、医药、软硬件科技、制造业等盈利相对平稳、轻资产或具备持续现金流的企业。
        
    - **读法**：分位值低于 20% 通常意味着处于历史低估安全边际，高于 80% 则进入历史过热/透支区间。
        
- **周期与重资产行业看「PB 历史分位」**：
    
    - **适用标的**：银行、券商、钢铁、煤炭、航运、矿产等重资产与强周期企业。
        
    - **原因**：这类行业在周期底部时净利润可能为负或断崖式下跌，导致 PE 暴增或失真，此时以净资产为底的 PB 历史分位才能提供有效的估值锚点。


### 指标分类与核心用途

| **指标**      | **指标属性**   | **能否单独看估值高低** | **核心参考意义**                    |     |
| ----------- | ---------- | ------------- | ----------------------------- | --- |
| **PE 历史分位** | **相对估值指标** | **最直观、最简单**   | 对比公司历史定价中枢，判断当前每单位利润卖得是贵还是便宜。 |     |
| **PB 历史分位** | **相对估值指标** | **辅助/特定行业核心** | 对比公司历史账面价值定价，适合周期股与重资产/金融行业。  |     |
| **ROE**     | **商业质量指标** | 否（需结合价格）      | 股东权益回报率，巴菲特最看重的商业壁垒与资本复利指标。   |     |
| **ROA**     | **运营杠杆指标** | 否（需结合价格）      | 总资产回报率，剔除负债杠杆后衡量企业底层真实的运营效率。  |     |

单纯看历史估值分位最大的风险是“价值陷阱”——如果一家公司由于行业技术迭代、竞争加剧导致 ROE 从 20% 永久性滑落至 8%，那么即使当前的 PE/PB 处于历史 0% 分位，也绝不是低估，而是中枢下移。最实用的极简原则是：**用 ROE 判断这门生意值不值得买，用 PE（或 PB）历史分位判断现在的价格能不能买。**


**实战中的组合用法**

- **选股第一步看 ROE**：寻找长期 ROE 稳定大于 15%~20% 的公司，锁定具备竞争壁垒和股东回报潜力的候选池。
    
- **验资第二步查 ROA 与杜邦结构**：
    
    - **优选（高质量高 ROE）**：高 ROE 主要是由高 ROA（如 ROA > 8%~10%）驱动，说明公司是靠**高净利率**或**极快周转**赚钱，底层护城河极深（例如白酒、软件、高精尖医药）。
        
    - **警惕（高风险高 ROE）**：ROE 很高但 ROA 极低（如 ROA < 2%~3%），说明超额收益完全是靠借债撬动，抗周期波动能力极弱。
        

对于茅台、腾讯等轻资产与高壁垒行业，ROE 与 ROA 差距较小，直接看 **ROE** 最有效；对于紫金矿业、招商银行或重工业制造等重资产行业，必须看 **ROA** 来确认资产真实回报率，再结合 ROE 综合评估负债扩张的性价比。
