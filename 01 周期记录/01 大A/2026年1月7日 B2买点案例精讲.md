# 活跃 MACD

> 活跃 4 只解决 MACD 水下第一次启动的问题，不解决零轴之上二次金叉启动的问题。
- 也就意味着，如果 MACD 零轴上面出现-2.3 后，暂停，一直等零轴之上二次金叉。
- MACD 水上第一个死叉不能作为波段结束的信号，但是要警惕。因为死叉后可能马上二次金叉。
	- 只关注活跃 -2.3，就停止，然后等活跃二次金叉。这个时候不用看活跃 4 了。活跃 4 不解决零轴上二次启动的问题。

- 总结：
	1. 零轴上二次死叉，
	2. 活跃-2.3

### 选股公式
COND1:=EXIST(REF(J,1)<18, 20);              { 前20日 J 值曾低于18 }
COND2:=ZF>4;                               { 涨幅大于 4% }
COND3:=VOL>=REF(VOL,1)*1.7;                { 成交量放量 1.7 倍以上 }
COND4:=J<85;                               { 当日 J 值小于 85 }
COND5:=IS_YANG AND UPPER_SHADOW<BODY*0.6;  { 阳线且上影线短于实体的60% }
COND6:=趋势白线>大哥黄线;                   { 趋势白线 大于 大哥黄线 }
